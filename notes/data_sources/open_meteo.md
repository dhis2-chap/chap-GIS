# Open-Meteo Historical Climate Archive

Free historical weather/climate API.

- **Variables:** Daily temperature, precipitation, evapotranspiration (1940–present)
- **Resolution:** ~9 km
- **Coverage:** Global
- **Access:** REST API at `https://archive-api.open-meteo.com/v1/archive`
- **Used in malaria-research:** `scripts/pf8_climate_explorer.py`; climate profiling at sampling locations
