# WorldPop

Gridded population estimates.

- **Variables:** Constrained population density (2020)
- **Resolution:** 100 m
- **Coverage:** Global; used for Rwanda, Tanzania, Uganda
- **Access:** HTTP download from `https://data.worldpop.org/GIS/Population/...`
- **Used in malaria-research:** `malaria_research/data/population.py`; population-weighted exposure calculations
