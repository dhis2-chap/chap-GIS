# geoBoundaries

Open administrative boundary polygons.

- **Variables:** ADM0 (country) boundaries (other levels available)
- **Format:** Vector polygons
- **Coverage:** Global; used for Rwanda, Tanzania, Uganda
- **Access:** GitHub raw content at `https://github.com/wmgeolab/geoBoundaries/raw/...`
- **Used in malaria-research:** `malaria_research/data/boundaries.py`; spatial masking and zonal statistics
