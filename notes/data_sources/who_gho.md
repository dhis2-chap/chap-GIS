# WHO Global Health Observatory (GHO)

Country-level health indicators via REST API.

- **Variables:** Malaria incidence, cases, deaths, ITN coverage, IRS coverage, RDT tests
- **Coverage:** By country (Rwanda and others)
- **Access:** REST API at `https://ghoapi.azureedge.net/api`
- **Used in malaria-research:** `malaria_research/data/who.py`, `scripts/download_who_malaria.py`; epidemiological data
