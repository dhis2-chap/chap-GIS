# Champion-curve exposure rasters — RWA 2021

The seven exposure-pipeline layers for Rwanda, year **2021**, using the
**champion thermal-suitability curve** from the suitability-curve search:

    S(T) = 1 / (1 + exp(-3 * (T - 23)))      # logistic threshold, T0=23 C, k=3

This sharp ~23 C threshold fit disease better than the Gaussian TPC
(Spearman vs incidence 0.515 vs 0.496). Spatial config is the optimum:
lambda=1500 m, gamma=100 m, water-edge buffer=2 px, 30 m grid.

Generated by `results/gen_champion_rasters_2021.py`. Because the pipeline's
`run()` hardcodes the Gaussian curve, suitability and exposure here are computed
directly via `compute_distance_field` / `exposure_from_field` (the same code
path `exposure()` uses internally) with the logistic curve substituted.

## Files

| file | dims | description |
|---|---|---|
| `breeding.nc` | lat×lon | breeding-site mask (WorldCover wetlands + rice + 2-px water-edge buffer) — same as Gaussian stack |
| `elev.nc` | lat×lon | elevation (m) — same as Gaussian stack |
| `temperature.nc` | lat×lon | annual-mean lapse-downscaled temperature (C) — same as Gaussian stack |
| `suitability.nc` | lat×lon | **logistic-threshold** thermal suitability (0–1); attrs record curve/T0/k |
| `population.nc` | time(1)×lat×lon | WorldPop 2021 |
| `expo.nc` | lat×lon | **the champion risk map** = base(lambda,gamma) · S_logistic(T_nearest) |
| `pop_exposure.nc` | time(1)×lat×lon | population × expo |
| `curve.json` | — | curve + config metadata |

## Notes
- vs the Gaussian stack in `../optimum_rasters_2021/`: only `suitability`,
  `expo`, `pop_exposure` differ; breeding/elev/temperature/population are
  identical (curve-independent).
- The logistic curve is far more selective: most pixels get ~0 suitability
  (median 0.002) and only the warmest, lowest areas light up — hence a sharper,
  higher-contrast risk map than the Gaussian.
- Read with `xarray.open_dataset(...)[var]` (the files carry a `spatial_ref`
  coordinate variable, so `open_dataarray` will complain).
- Like all parameters here, the 23 C threshold is a data-driven fit for cool
  highland Rwanda, not a mechanistic constant.
